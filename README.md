# CloudPulse - Netlify & Database Demo App 🚀

A modern, production-ready demo website engineered for instant deployment to **Netlify** with continuous integration via **GitHub** and plug-and-play **Cloud Database (Supabase PostgreSQL)** integration.

---

## ✨ Features

- **Instant Deployment**: Pre-configured `netlify.toml` with edge redirects, caching, and security headers.
- **Serverless API Function**: Located at `netlify/functions/api.js` (accessible at `/.netlify/functions/api` or `/api`).
- **Interactive Database Board**:
  - Out of the box: zero-setup **LocalStorage** persistence.
  - 1-click cloud sync: **Supabase PostgreSQL** integration with Row-Level Security (RLS) support.
- **Modern Responsive Design**: Glassmorphic theme, responsive mobile-first grid, CSS custom properties, and zero build dependencies.

## ⚡ Quick Start (Local Testing)

You can open `index.html` directly in your browser or run any local HTTP server:

```bash
# Option 1: Python 3 simple HTTP server
python3 -m http.server 8080

# Option 2: Using npx serve
npx serve .

# Option 3: Netlify CLI (enables local serverless functions)
npx netlify dev
```

Visit `http://localhost:8080` to interact with the app.

## 🐙 Step 1: Uploading to GitHub

1. Open your terminal in this directory:
   ```bash
   cd netlify-demo
   ```

2. Initialize Git and make the first commit:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of Netlify demo website"
   ```

3. Create a repository on GitHub:
   - Go to [GitHub New Repo](https://github.com/new) and name it `netlify-demo`.
   - Leave it empty (do NOT initialize with README).

4. Link and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/netlify-demo.git
   git push -u origin main
   ```
   *(Or using GitHub CLI: `gh repo create netlify-demo --public --source=. --push`)*

## 🚀 Step 2: Deploying to Netlify

### Method A: Automated Continuous Deployment (Recommended)
1. Go to [Netlify Dashboard](https://app.netlify.com).
2. Click **Add new site** ➔ **Import an existing project**.
3. Choose **GitHub** and authorize access.
4. Select your `netlify-demo` repository.
5. In build settings:
   - **Build command**: *(leave blank)*
   - **Publish directory**: `.` *(current directory)*
6. Click **Deploy Site**. In ~15 seconds, Netlify generates your live HTTPS URL!

### Method B: Drag and Drop (No Git required)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `netlify-demo` folder into the dropzone.
3. Your site is deployed immediately.

## 🗄️ Step 3: Connecting a Cloud Database (Supabase)

This demo uses **Supabase**, the industry-standard open-source Firebase alternative powered by PostgreSQL.

1. **Create Project**: Sign up for free at [supabase.com](https://supabase.com) and create a project.
2. **Create Table**: Open the **SQL Editor** in Supabase and run:
   ```sql
   CREATE TABLE messages (
     id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     author TEXT NOT NULL,
     category TEXT NOT NULL,
     content TEXT NOT NULL,
     likes INT DEFAULT 0,
     created_at TIMESTAMPTZ DEFAULT NOW()
   );

   ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
   CREATE POLICY "Allow Public Access" ON messages FOR ALL USING (true) WITH CHECK (true);
   ```
3. **Get API Keys**: Go to **Project Settings ➔ API**. Copy:
   - `Project URL`
   - `anon / public` API key
4. **Connect in App**:
   - In your deployed app, click **"Configure Cloud Database"** (or the DB indicator in the navbar).
   - Switch to **Supabase**, paste your URL and Anon Key, and click **Save & Apply**.
   - Your messages will now persist in real-time in your cloud PostgreSQL database!
