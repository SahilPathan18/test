3 Steps to Take This Live

Full details are also included in your companion PDF guide.

01

Upload to GitHub

Initialize git, commit these files, and push to your GitHub account repository.

git init
git add .
git commit -m "Initial commit"
git push -u origin main
02

Link with Netlify

Log in to Netlify, select "Add new site" ➔ "Import an existing project", and pick your GitHub repo.

Build command: (leave blank)
Publish directory: .
03

Connect Database

Create a free Supabase or Firebase project, create a table, and paste the URL & Key in Netlify Environment Variables.

SUPABASE_URL=https://xyz.supabase.co
SUPABASE_ANON_KEY=eyJhbGci...
